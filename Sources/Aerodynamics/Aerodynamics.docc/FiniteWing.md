# Equivalent finite-wing correction

Add bounded induced-angle and induced-drag corrections to a supplied section polar.

``FiniteWingAirfoil`` implements ``AirfoilCoefficientModel`` and can wrap a
``TabulatedAirfoil`` or another checked polar. This is a steady equivalent-wing
approximation for attached, low-speed flow. It is not a spanwise lifting-line solver,
a wake model or a hypersonic correction.

## Physical model

For aspect ratio `AR = span² / area` and supplied span efficiency `e`, solve:

```text
alpha = alphaEffective + CL(alphaEffective) / (pi e AR)
alphaInduced = CL / (pi e AR)
CDinduced = CL² / (pi e AR)
CDtotal = CDprofile(alphaEffective) + CDinduced
```

The underlying polar supplies profile drag only. Do not wrap data that already
contains finite-wing induced drag, combine this correction with a second induced-drag
model, or also apply its induced angle as a separate local-flow correction.
Moment is the underlying polar's moment at effective incidence, about its original
moment reference. This simple model does not predict finite-wing changes to that
moment reference or spanwise pressure distribution.

For a linear polar with slope `a0`, the resulting wing lift slope is
`a = a0 / (1 + a0 / (pi e AR))`. Cambered polars retain their zero-lift offset through
the implicit solution rather than simply multiplying all coefficients by a factor.
The induced-drag basis is [NASA's induced-drag coefficient relation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/induced-drag-coefficient/).

## Explicit coverage and solver limits

The caller declares an attached-flow effective-angle bracket covered by the polar,
and a separate geometric operating-angle interval. The implementation restricts
aspect ratio to at least four, Mach to at most 0.3, and both angle intervals to
±0.35 radians. These are deliberately chosen model limits, not an accuracy certificate.
Calibrating efficiency and confirming attached flow remain responsibilities of the
supplied aerodynamic data; the model does not detect stall or separation.

Bisection solves the angle residual with a configurable tolerance and iteration
budget. ``FiniteWingSolution`` returns effective angle, induced angle, induced drag,
coefficients, residual and iterations. Input coverage errors from the polar propagate.
An unbracketed solution or exhausted budget throws ``FiniteWingError``; there is no
silent fallback to infinite-wing coefficients. Multiple/post-stall roots are outside
the intended physical assumptions, and numerical convergence does not prove uniqueness.

```swift
import Aerodynamics
// `polar` is a caller-supplied checked, attached-flow airfoil model.
let corrected = try FiniteWingAirfoil(airfoil: polar,
    aspectRatio: 8, spanEfficiency: 0.8,
    effectiveAngleRangeRadians: -0.2...0.2,
    operatingAngleRangeRadians: -0.15...0.15)
let solution = try corrected.solve(angleOfAttackRadians: 0.1,
    reynoldsNumber: 1_000_000, machNumber: 0.2)
```

## Use with wing strips

For uniform geometry and flow, the equivalent coefficient model can be wrapped in
``AirfoilWingSectionModel`` and supplied to ``SegmentedWing``. Use the **whole wing's**
aspect ratio on every strip, never the individual strip's aspect ratio. Uniform-wing
forces then do not depend on segmentation resolution.

Applying this equivalent model separately to arbitrary twisted, controlled or
nonuniformly loaded strips is not a true coupled finite-wing calculation. Such cases
require spanwise circulation/induced-flow coupling or validated finite-wing datasets.
Tail interference and downstream wake velocities are not generated by this model.

`swift run FluidPhysicsDemo` demonstrates the correction on a uniform rectangular
wing with synthetic data. Tests compare with the analytic linear-polar result,
cambered and infinite-aspect-ratio limits, signed lift and positive induced drag,
explicit coverage/bracketing/budget failures and uniform strip-count independence.

For a straight wing with supplied linear polars and spanwise incidence/chord
variation, see <doc:LiftingLine> for the bounded coupled solver.
