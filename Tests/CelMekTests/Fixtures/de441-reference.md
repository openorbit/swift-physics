# Independent DE441 regression references

`de441-testpo.json` contains numerical reference facts selected from JPL's
independently supplied `testpo.441`, not output generated by the Swift reader.
Source: https://ssd.jpl.nasa.gov/ftp/eph/planets/ascii/de441/testpo.441
Source SHA-256: e60c08ced7741a07d4dfe89b124afb4b1648bd1e3d0eb68dd9a79bf6990bb9c2

Regenerate from a local reference file, with no external library or network:

```sh
python3 Tools/extract_de441_reference_fixtures.py Data/DE441/testpo.441 Tests/CelMekTests/Fixtures/de441-testpo.json
```

The selection covers all six vector components of targets 1–13 and all four
nutation components of target 14. It includes record-boundary and interior
position/derivative cases for Earth, Moon, EMB and nutation, modern relative
Earth/Moon/EMB components for the SI adapter, and widely separated epochs across
the supported local binary subset. Native vector units are AU and AU/TDB-day;
nutation units are radians and radians/TDB-day. The absolute native tolerance
is 1e-12; adapter tolerances multiply it by the appropriate SI/rate scale.
Identifiers are JPL testpo identifiers, not NAIF IDs; centre 12 is SSB.

The fixture's contents and coverage mix are checked even without external data.
Numerical comparisons run only if the optional native binary exists in
Data/DE441 or CELMEK_DE441_DATA_DIRECTORY; testpo.441 is not required for these
pinned checks. Invalid present binaries fail. Full testpo scanning remains an
additional optional validation path, not a replacement for pinned cases.
These checks establish reader agreement with JPL reference interpolation;
they do not certify the ephemeris's physical accuracy at every epoch.
