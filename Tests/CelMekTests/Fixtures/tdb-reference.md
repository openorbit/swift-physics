Geocentric TDB−TT samples generated with external ERFA 2.0.1 eraDtdb.
Source: https://github.com/liberfa/erfa/blob/v2.0.1/src/dtdb.c
Generator: Tools/characterize_tdb_adapter.py.

TT dates are supplied as (2451545, daysSinceJ2000), as permitted by the
reference. UT1, longitude and observer coordinates are all zero; u=v=0
removes topocentric terms. Rate and acceleration are centred differences of
the reference offset with a 300-second step. The stored rate is d(TDB−TT)/dTT,
so add 1 to obtain dTDB/dTT. Acceleration is d²(TDB−TT)/dTT².

4,874 samples: four six-hour phases every 30 days from 1950-01-01 TT through
2050-01-01 TT, plus final endpoint and J2000. These are independent reference
values, not snapshots generated by the Swift approximation. See TIME.md and
TDB_CHARACTERIZATION.json for measured limitations and denser survey results.
No external reference library is needed to run the Swift tests.
